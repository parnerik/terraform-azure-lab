# Terraform Azure Lab

This repository contains my Terraform labs for Microsoft Azure.

The goal of this project is to learn Infrastructure as Code (IaC) using Terraform while deploying and managing Azure resources.

## Technologies

- Terraform
- Microsoft Azure
- Azure CLI
- Git
- GitHub

## Completed

- Azure authentication using Azure CLI
- Terraform provider configuration
- Resource Group deployment
- Terraform plan/apply/destroy workflow
- Git version control

## Planned

- Storage Accounts
- Virtual Networks (VNets)
- Subnets
- Network Security Groups (NSGs)
- Linux Virtual Machines
- Azure Key Vault
- Managed Identities
- Azure Backup

## Requirements

- Terraform
- Azure CLI
- Azure Subscription

## Usage

Initialize Terraform:

```bash
terraform init
```

Preview changes:

```bash
terraform plan
```

Deploy infrastructure:

```bash
terraform apply
```

Remove infrastructure:

```bash
terraform destroy
```
